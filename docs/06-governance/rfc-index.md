# RFC Index

RFC (Request for Comments) — предложение архитектурного решения до утверждения: проблема → варианты → сравнение → риски. После утверждения оформляется как ADR (см. `adr-index.md`).

Простыми словами: RFC — это "черновик решения на обсуждение", ADR — "решение, которое уже приняли и записали навсегда".

## Как это использовалось на Этапе 1

Для решений ADR-0001…0003 отдельного RFC-документа не заводилось — сравнение вариантов было частью самого документа `Architecture Overview` (разделы 3-5), а утверждение происходило прямо в диалоге. Это допустимо для решений, целиком укладывающихся в один документ; отдельный RFC-файл имеет смысл, когда:
- решение затрагивает несколько уже утверждённых документов одновременно;
- решение требует длительного обсуждения/нескольких итераций до утверждения;
- решение инициируется не при первом написании документа, а как пересмотр уже принятого (например, будущий пересмотр ADR-0001 из-за риска локализации данных).

## Шаблон RFC (для будущих решений)

```
# RFC-XXXX: <заголовок>
Статус: Draft / Under Review / Accepted / Rejected
Дата:
Инициатор:

## Проблема
## Рассмотренные варианты
## Сравнение
## Рекомендация
## Риски
```
