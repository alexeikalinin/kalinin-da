## Правила ведения

- ADR не редактируется задним числом после принятия (Accepted) — отменяется только новым ADR со статусом Superseded у старого.
- Номер ADR — сквозной, не переиспользуется.
- Каждый ADR — результат RFC-анализа (сравнение вариантов), утверждённого пользователем. Для ADR-0001…0003 анализ вариантов зафиксирован в `Architecture Overview` (разделы 3–5) — это заменило отдельный RFC-документ, так как сравнение уже было частью основного документа этапа.
