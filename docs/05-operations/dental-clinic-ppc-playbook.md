# Стоматология: PPC playbook по направлениям (Минск + Минская область)

Реюзабельная база знаний по спросу и структуре кампаний для стоматологических клиник в Минске. Родилась из разведки для конкретного проспекта (МаякДент, mayakdent.by, сентябрь 2026) — но сама разведка сделана не по бренду клиники, а по услугам, поэтому применима к любой стоматологии в Минске с похожим набором услуг, не только к МаякДент. Если МаякДент не подтвердит запуск, этот документ — готовая база для питча аналогичного пакета другой клинике без повторного прогона.

Живой клиентский медиаплан по имплантации/протезированию для МаякДент — отдельный артефакт (см. `project_medavenue_client_setup`-style запись в памяти агента; ссылка на артефакт хранится в истории диалога с пользователем, не дублируется здесь).

## Методология (общая для всего документа)

- **Источник объёма:** Yandex Cloud Search API (Wordstat), гео Минск (region id `157`) + Минская область (region id `10723`), суммарно. Live-запрос, не оценка.
- **Google Keyword Planner:** для Беларуси системно не отдаёт объём по узким гео на большинстве фраз — из ~30 сид-фраз в разведке возвращает статистику по 2–3. Использовать только как источник диапазона top-of-page bid (low/high), не как источник объёма. Объём по Google оценивать как **≈50% от объёма Яндекса** (типичное для рынка РБ соотношение долей поисковиков в локальных медицинских запросах) — это допущение, не измерение.
- **Прогноз ставок Яндекс Директ (`forecasts.create`)** — недоступен, эндпоинт отвечает `404` (проверено live 2026-09-03, снят Яндексом с публичного API целиком). Не пытаться использовать как источник CPC/CTR-прогноза, пока Яндекс не восстановит.
- **Wordstat отдаёт top-20 фраз на сид-запрос** — это видимая часть ядра. Длинный хвост (узкие гео-формулировки, бренды, симптомные запросы, рассрочка/кредит) добавляет по опыту агентства ещё +40–70% объёма при расширении на широкое соответствие.
- Цифры ниже — частота показов в месяц по данным Wordstat, снятая 2026-09-03. Пересверять раз в 2–3 месяца перед реальным использованием в питче — сезонность в стоматологии заметная (отбеливание/эстетика растёт к лету и Новому году, снижается в январе).

## Сквозные находки по всей категории

- **Шум от животных.** «чистка зубов» (2522/мес) и «ультразвуковая чистка зубов» (200/мес) заметно засорены запросами про чистку зубов собакам/кошкам (≈250 и ≈65 соответственно). Минус-слова «собаке», «собак», «кошке», «коту», «животным» — обязательны для гигиены и отбеливания.
- **Геошум из других городов СНГ.** Почти во всех кластерах Wordstat подмешивает Гомель, Ростов-на-Дону, Спб, Ставрополь, Нижний Новгород, Брянск, Волгодонск, Москву, Семилуки — несмотря на региональный фильтр (это фразы, где город указан явно в самом запросе, а пользователь физически в Минске/области ищет как раз с указанием чужого города — типичный шум, не путать со случаями, когда региональный фильтр работает неверно). Минус-слова на уровне аккаунта: перечисленные города + любые другие явно нецелевые.
- **«Каппы» — не про ортодонтию у этой категории клиник.** Объём крошечный (15–23/мес) и разбит между «капа для зубов» и «капа для выравнивания зубов» — если у клиники нет брекет-направления, эта услуга низкоприоритетна для платного трафика, органики достаточно.
- **Нулевые/около-нулевые сервисы.** «Полукоронки» (0), «цифровой дизайн улыбки / wax-up» (0), «лечение корневых каналов» как отдельная фраза (20) — это реальные услуги на сайтах клиник, но у них нет самостоятельного спроса в поиске. Не стройте под них отдельную кампанию — это ад-группы или пункты на лендинге более широкой кампании (терапия/эндодонтия, эстетика).
- **«Стоматология минск» — это не таргетируемый кластер, а рынок.** 21 835/мес, но состоит в основном из брендовых запросов (конкретные клиники по названию/номеру: «5 стоматология минск», «7 стоматология минск», «стоматология дент минск»), геолокационных модификаторов («стоматология на минском [ш.]») и небрендовой навигации («поликлиники стоматологии», «детская стоматология»). Использовать только для охватовой РСЯ/КМС-кампании на узнаваемость или как основу медийного ретаргетинга — никогда как ядро performance-кампании.

| Кластер | Частота/мес | Заметки |
|---|---|---|
| Виниры (общее) | 1 733 | крупный кластер, «виниры минск» — 427 отдельно |
| Виниры — цена | 163 | high-intent подкластер |
| Отбеливание зубов (общее) | 603 | |
| Отбеливание — гео (минск) | 103 | подкластер общего |
| Домашнее отбеливание | 12 | низкий самостоятельный спрос — ад-группа, не кампания |
| Офисное отбеливание | 20 | тоже низкий — объединять с общим кластером отбеливания |

**Структура кампании «Эстетика».** 1 кампания на платформу, 2 ад-группы: **Виниры** (виниры минск, виниры цена, виниры на передние зубы, керамические виниры цена) и **Отбеливание** (отбеливание зубов минск, отбеливание зубов цена, офисное/домашнее — объединить в один таргетинг, не разносить). Оффер: бесплатная консультация + фото «до/после», у виниров сильно работает визуальный контент (сайт, объявления с расширениями-изображениями).

**Минус-слова:** «своими руками», «дома без стоматолога», «сода» (частый шум для отбеливания — люди ищут домашние рецепты, не услугу).

## Направление: Терапевтическая стоматология

| Кластер | Частота/мес | Заметки |
|---|---|---|
| Лечение зубов (общее, зонтичный запрос) | 2 154 | самый широкий вход в терапию, включает поднаправления |
| Лечение кариеса | 336 | самый чёткий коммерческий подкластер |
| Пломба — цена | 85 | high-intent, малый объём |
| Художественная реставрация зубов | 49 | нишевый, эстетический подтип терапии |
| Лечение корневых каналов | 20 | почти нет самостоятельного спроса — часть «лечение зубов» |

**Структура кампании «Терапия».** 1 кампания, ад-группы: **Кариес** (лечение кариеса минск, лечение кариеса цена), **Общая терапия** (лечение зубов минск, лечение зуба под наркозом/седацией — эти модификаторы неожиданно частотны, 151–191/мес, целевая аудитория боится боли — сильный оффер), **Реставрация** (художественная реставрация зубов минск).

Это направление обычно самое дешёвое по CPC и самое массовое по объёму, но самый низкий чек — используется как «воронка знакомства» с клиникой, а не как основной источник выручки. Хорошо работает как вход для допродажи имплантации/протезирования на следующем визите.

## Направление: Хирургическая стоматология (без имплантации)

| Кластер | Частота/мес | Заметки |
|---|---|---|
| Удаление зуба (общее) | 4 619 | **самый большой кластер во всей категории услуг** |
| Удаление зуба мудрости | 1 504 | отдельная клиническая процедура, свой лендинг оправдан |
| Удаление зубов — цена | 206 | |
| Синус-лифтинг | 213 | часто идёт паттерном к имплантации, но ищут и отдельно |

**Структура кампании «Хирургия».** 1 кампания, 2 ад-группы: **Удаление зуба мудрости** (отдельно — другая тревожность у пациента, другой оффер про седацию/наркоз) и **Удаление зуба — общее** (удаление зуба цена минск, удаление корня зуба). Синус-лифтинг — ад-группа внутри имплантационной кампании (это подготовительная процедура к имплантации, а не отдельная услуга для отдельного пациента).

**Важно:** это направление имеет самый высокий объём во всей стоматологической категории и его почти никогда не рекламируют отдельно (клиники фокусируются на имплантации/эстетике как более маржинальных). Это структурная возможность — дешёвый вход в клинику + кросс-селл на имплантацию после удаления зуба мудрости или разрушенного зуба.

## Как использовать этот документ для питча другой клинике

1. Проверить, какие направления реально есть на сайте клиники-проспекта (не все клиники предлагают все 7 направлений — например, без своей хирургии или без ортодонтии).
2. Взять из таблиц выше только релевантные кластеры, сложить в семантическое ядро.
3. Применить ту же логику бюджетного минимума: количество кампаний (не направлений!) × $5–8/день — см. феномен, пойманный на МаякДент.
4. Данные по объёму актуальны на 2026-09-03 — при разрыве больше 2–3 месяцев перезапросить Wordstat заново, а не переиспользовать эти цифры как есть.
